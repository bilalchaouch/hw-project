QUESTION: What colour does each paragraph render, and why?

---

1. <p>Plain paragraph</p>
   Applied rule: p { color: blue; }
   Specificity: 0-0-1 (element selector)
   Rendered colour: BLUE
   Reason: Only one rule matches. Element selectors have the lowest specificity (0-0-1).

---

2. <p class="text">Paragraph with class="text"</p>
   Competing rules: p (0-0-1) vs .text (0-1-0)
   Rendered colour: GREEN
   Reason: The class selector .text has higher specificity (0-1-0) than the element selector p (0-0-1). Specificity comparison: 0-1-0 > 0-0-1.

---

3. <p class="text"> — with the additional p.text rule
   Competing rules: p (0-0-1), .text (0-1-0), p.text (0-1-1)
   Rendered colour: RED
   Reason: p.text combines an element and a class selector, giving specificity 0-1-1, which beats .text (0-1-0) and p (0-0-1).

---

4. <p id="unique" class="text">...</p>
   Competing rules: p (0-0-1), .text (0-1-0), p.text (0-1-1), #unique (1-0-0)
   Rendered colour: PURPLE
   Reason: ID selectors have specificity 1-0-0, which always beats class (0-x-x) and element (0-0-x) selectors. #unique wins.

---

5. <p class="text highlight">...</p>
   Competing rules: p (0-0-1), .text (0-1-0), p.text (0-1-1), p.text.highlight (0-2-1)
   Rendered colour: ORANGE
   Reason: p.text.highlight has two class selectors + one element = specificity 0-2-1, which beats p.text (0-1-1).

---

SPECIFICITY CALCULATION SUMMARY
=================================
Format: (inline styles, IDs, classes/pseudo-classes/attributes, elements)

Selector          | Specificity | Colour
------------------|-------------|--------
p                 | 0-0-0-1     | blue
.text             | 0-0-1-0     | green
p.text            | 0-0-1-1     | red
#unique           | 0-1-0-0     | purple
p.text.highlight  | 0-0-2-1     | orange

KEY TAKEAWAYS:
- ID selectors (1-0-0) always beat class and element selectors.
- Each class/pseudo-class adds 0-1-0; each element adds 0-0-1.
- When specificity is equal, the LAST rule in source order wins.
- !important overrides all specificity (use sparingly).
- Inline styles have the highest specificity (1-0-0-0 effectively).
