CSS Specificity Exercise

This page demonstrates CSS specificity rules as practised in Lab 4 — Exercise 1. The live elements below show which rule wins when multiple selectors target the same element.

Live Demo

1. Plain paragraph — element selector p → blue (0-0-1)

2. Paragraph with class="text" — .text wins → green (0-1-0)

3. Same as above but p.text rule also applies → red (0-1-1 beats 0-1-0)

4. Has id="unique" — #unique wins → purple (1-0-0)

5. Has class="text highlight" — p.text.highlight → orange (0-2-1)

Answers & Explanation

Q: What colour does each paragraph render, and why?

  1. Plain <p>: renders blue. Only the p element selector (0-0-1) applies.
  2. <p class="text">: .text (0-1-0) beats p (0-0-1), so green.
  3. <p class="text"> with p.text rule: (0-1-1) beats (0-1-0), so red.
  4. <p id="unique" class="text">: ID selector (1-0-0) beats all class/element combos, so purple.
  5. <p class="text highlight">: p.text.highlight (0-2-1) beats p.text (0-1-1), so orange.

Key rule: Specificity is calculated as (inline, ID, class/pseudo-class/attribute, element). Higher specificity wins regardless of source order, unless !important is used.
